# Design decisions

journal-browser's shape comes from a run of owner verdicts made between October 22 and October 30, 2026, recorded in the untracked register `docs/decisions.md`. This page curates the load-bearing ones, grouped by theme. Each entry gives the decision, the why, where it landed, and its later fate if it was amended or reversed. Because `docs/` is gitignored (since commit `2d65f23`), the register itself has no git history; the commit hashes below are the recorded anchors between decisions and code. For the chronology, see [Lore](../lore.md); for how the chosen sources flow through harvest, see [Data pipeline](../systems/data-pipeline/index.md).

## Deals: primary sources and the manual register

**Deal data comes from primary sources, never scraped from the old browser** (D1, `fadb224`). The original rule was the cOAlition S JCT public dump amended with openaccess.nl data. The reasoning is durability: openly licensed registers and the canonical Dutch narratives beat a fragile scrape of the WUR-hosted tool the project replaces. The harvest code lives in `backend/src/journal_browser/harvest/openaccess_nl.py` and `backend/src/journal_browser/harvest/jct.py`.

**openaccess.nl is the canonical deal register; JCT is enrichment only; no PDF auto-parse** (D13, `ea1feca`). JCT's consortium sheets do not reliably enumerate members, so JCT absence is never evidence a deal does not exist. Contract PDFs stay linked through `deals.contract_url` and are read by the human curator; structured terms are recorded only after human confirmation. Landed in the two harvesters above plus `backend/src/journal_browser/routers/journals.py`, which treats every canonical current deal as applicable. Fate: the curation-pending badge this decision introduced was superseded by D14.

**The register is manual and Twente-only, then partly reversed** (D14, `37258de`). The owner ruled that register-only rows (De Gruyter Brill and similar) are not Twente deals, so 595 rows were purged, 16 kept, and every automatic deal writer was deleted so hand-curated data can never be overwritten. Fate: reversed in part on October 25, 2026 (`2f9b5f8`, `c00b587`): auto-harvest was restored so a fresh instance can bootstrap itself, while the manual rows survive in the live database. The tension between the two registers remains an open question (see `docs/data-pipeline/OVERVIEW.md` §6).

**A curation dismissal remembers what it dismissed** (November 1, 2026, migration `backend/alembic/versions/0045_curation_resolved_reason.py`). Clearing `needs_curation` used to write a blanket `False` override, which also silently suppressed every future curation reason on that deal and lost the dismissed text. The harvest now consults `deals.curation_resolved_reason`: the flag stays cleared only while the page produces exactly that reason, any other reason re-flags, and a clean page retires the marker. Landed in `backend/src/journal_browser/harvest/openaccess_nl.py` and `backend/src/journal_browser/routers/admin/deals_admin.py`. Still current.

## The journal universe and how it is classified

**One ISSN-L-keyed journal universe, everything denormalized onto the row.** A single OpenAlex sources sweep stores 268,874 sources and normalizes 177,181 journals, each keyed by ISSN-L. DOAJ stamps, OpenAPC costs, Scimago quartiles, publisher lineage, topics, and embeddings all denormalize onto that row, so serving needs no joins across sources. Landed in `backend/src/journal_browser/harvest/openalex_journals.py`, `backend/src/journal_browser/harvest/issn_backfill.py`, and `backend/src/journal_browser/models/journals.py`. Still current.

**A hard cutoff replaced the quality bar** (D12 to D15, `57df32e`, `37258de`, migration `0007`). The first presentation filter (type, ISSN-L, DOAJ or Scimago or deal coverage or recent activity) put 138,834 of 177,181 journals in default scope against a 50 to 70k estimate, so it was judged arbitrary and dropped. The presented corpus is now every journal with `works_2020_plus > 3`. The flag that drives it is `journal_flags.works_window_plus`, and the cutoff applies inside `backend/src/journal_browser/services/search/` so every surface inherits it. Still current.

**Journal OA type is derived at read time, never harvested** (D17, October 23, 2026). No per-journal OA status exists in OpenAlex source records, so `oa_type` is computed at query time in `backend/src/journal_browser/services/search/classify.py` and never stored. Fate: amended on October 27 (`e6ff2ff`) to observe venue color from recent works, then reworked on October 28 into the DOAJ-canon decision tree below.

**DOAJ is the most trustworthy canonical OA source** (October 28, migrations `0029` and `0030`, harvester committed as `29ad8d4`). DOAJ's own `has_apc` declaration splits gold from diamond; a DOAJ-listed venue without charges is diamond; an OA venue with no model evidence gets a new `generic` bucket instead of an overeager diamond. The rework fixed a bug chain in which a fully OA MDPI journal displayed as closed (`0dc91af`, `e6ff2ff`). Landed in `backend/src/journal_browser/harvest/doaj.py` and `classify.py`.

**Publishers are canonicalized through OpenAlex lineage** (October 27, `23ef3ed` through `0712412`, latest-known deal attribution `59b11ce`). An imprint resolving to its parent (LWW showing as Wolters Kluwer) and contracts attributed to publishers who changed name motivated canonical top-level lineage plus flip flags. Landed in `backend/src/journal_browser/harvest/publishers.py` and `backend/src/journal_browser/services/publishers.py`. Still current.

## The works corpus and the author path

**The Pure-derived corpus is canonical for the institution** (D18, October 23, 2026). Detail-page publication lists and institutional totals come from the canonical Pure corpus rather than the OpenAlex mirror, because "what has Twente published" deserves the institutional source of record. Landed in `backend/src/journal_browser/services/ut_metadata.py`. Fate: the DSN admin surface was dropped (`08e4356`), and the dependency itself was then removed by D27/D28 below.

**Preprints and books are excluded; conference proceedings stay** (D25, October 26, 2026, recorded with `d03f1ba`, `54d90d9`, `eb31a79`). OA numbers are the product, so preprint and book-family work types drop out of every count, list, and stat through `EXCLUDED_WORK_TYPES` in `backend/src/journal_browser/config.py` and `normalize_work_type` in `backend/src/journal_browser/vocab.py`. Proceedings stay deliberately: they are indistinct in the source vocabularies and legitimately OA-relevant. Still current.

**The author path is standalone; `author_source` selects the backend** (D27/D28, October 30, 2026, migration `backend/alembic/versions/0035_standalone_author_path.py`). journal-browser must run from data it harvests itself, because other institutions will not have the UT-local ut-metadata platform. The replacement ships local CERIF stores, a ported identity-resolution cascade, and admin identity review; `author_source=local` is the default in `backend/src/journal_browser/config.py` and `author_source=utmd` restores the old DSN behavior. Landed in `backend/src/journal_browser/harvest/author_ids.py`, `backend/src/journal_browser/services/work_sources.py`, and `backend/src/journal_browser/services/authors.py`.

## Platform

**A boring, ownable stack** (D2 to D5, D8, `e4e57a6`). FastAPI with SQLAlchemy 2 async on Postgres 17, Next.js on the frontend, docker compose for deployment, `uv` for Python, plain `uv run` jobs with a raw landing zone, and metrics collected only (no derived substitutes). The OpenAlex, OpenAIRE, and Crossref clients are the project's own bibliofabric family (`aletheca`, `aireloom`, `stavrophora`), already proven in `ut-metadata`. Fate: stable; the stack has not wavered since the first commit.

**Set env, boot, auto-harvest** (October 25, 2026, `28bde61`, `0ee46b6`). A fresh instance should fill its own database: a one-shot `bootstrap` service runs `backend/jobs/bootstrap.py` as a two-layer DAG, and the backend stays down until the pipeline succeeds. Landed in `backend/jobs/bootstrap.py` and `docker-compose.yml`. See [Bootstrap DAG](../systems/data-pipeline/bootstrap-dag.md).

**Multi-institution shared core, no aliases** (October 26, 2026, `0ea63ba` through `8d20bb8`). One deployment hosts several institutions over a shared data core at `/{code}` paths, cut over in coordinated phases rather than kept as an aliasing layer. The Groningen test deployment was retired the same day (`2c2d54b`); the `rug` institution row remains. Landed in `backend/src/journal_browser/routers/institutions.py` and `docs/multi-institute.md`. See [Multi-institution core](../features/multi-institution.md).

**Embeddings power semantic search; the GPU stays out of the API image** (D21, October 23, 2026, `c40f38b`, `e7eedd3`, HNSW `b2ebe90`). Every journal carries a 384-dim bge-small embedding over cleaned title, topics, and top works, which gives semantic search and three similar-journal lists. Passage encoding runs as a host-side GPU job; query encoding uses fastembed ONNX on CPU inside the API container, so torch never ships in the serving image. Landed in `backend/src/journal_browser/services/embeddings.py`, `backend/jobs/embed_journals.py`, and `db/Dockerfile`. See [Search and discovery](../systems/search.md).
